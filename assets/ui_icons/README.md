# 通用 SVG 图标

36 个原创 MIT 图标，采用 Folio 风格的轻量线条，覆盖导航、完成提示、退格、播放、暂停、Wi-Fi、电池、USB、TF、断开状态、太阳／月亮配色开关、键盘修饰键和框架应用入口和控制中心。`currentColor` 由 Rust 绘制时提供 tint，完成图标使用当前主题色圆面与白色勾选，按番茄钟的弹出／扩散时序绘制。

从项目根目录运行 `python3 scripts/generate-vector-icons.py --check` 可验证源与静态 Rust 几何一致。许可见 [LICENSE](LICENSE)，绘制路径见 [矢量图标说明](../../docs/vector-icons.md)。
