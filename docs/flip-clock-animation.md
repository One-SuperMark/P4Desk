# Pad 翻页时钟动画

## 本次调整

用户确认 DINish Heavy 字体与中轴位置后，反馈原动画只像“抖一下”。原版持续 240 ms，以 33 ms 门限重绘，移动半页只作等宽的垂直压缩。新版在原 tiny-flutter / tiny_gfx 中实现刚性半页的透视投影，保留已确认的静止字体、数字尺寸、三卡片布局和固定中轴。

| 阶段 | 时间 | 可见内容与运动 |
| --- | --- | --- |
| 上半页落下 | 0–280 ms | 旧数字上半页绕中轴向前转动，逐渐加速；露出下面的新数字上半页 |
| 正反面交接 | 280 ms | 活动页经过 90°，只剩薄边；新上半页与旧下半页可见 |
| 下半页展开 | 280–540 ms | 同一页片的背面带着新数字下半页展开，逐渐减速 |
| 接触与落稳 | 540–640 ms | 下半页轻微抬起一次再落稳，抬起角度上限小于 12°；卡片与中轴保持不动 |
| 静止 | 640 ms 后 | 使用原生 alpha8 字形绘制，完整显示新时间 |

只翻转发生变化的卡片。时间由单调时钟推进；常规重绘门限从 33 ms 改为 20 ms，一次动画最多提供 32 次局部重绘时机（含最终静止帧），并保证延迟循环最终补交静止帧。**重绘门限不是实测 LCD 帧率**，实际呈现还取决于 Rust 渲染、整屏旋转复制与 LCD 完成事件。

## 绘制方法

先绘制静止的新上半页和旧下半页，再绘制投影后的活动页。旧页正面在前 90° 可见，后 90° 切换到带有新数字的背面。活动页明暗随角度变化，投向静止页的软阴影随自由边移动；中心折线固定不动。

以中轴为原点，半页内距离为 `s`，翻转角度为 `θ`，观察距离 `d = 卡片高度 × 7`：

```text
透视倍率 k = 1 / (1 - s × sin(θ) / d)
投影垂直距离 v = s × abs(cos(θ)) × k
投影水平坐标 x = 卡片中心 + 原水平偏移 × k
扫描行反求 s = v / (abs(cos(θ)) + v × sin(θ) / d)
```

自由边靠近观察者时逐渐变宽，使页片呈梯形；数字跟随同一个投影，不单独移动。相邻卡片间隙为 24 px，原生尺寸下单边透视扩展小于 12 px。变化卡片的 dirty 扩展到每边 16 px，覆盖活动页与阴影，防止边缘残留。

扫描行反求只在每行进行浮点计算。字形采用整数双线性 alpha 采样，水平坐标以 Q16 累加、Q8 采样，减小边缘跳动和累计偏移。每次绘制只使用 352 个 RGB565 像素的行缓存和 256 项色表，两者合计 1,216 字节；没有逐帧分配整页纹理或全屏临时图像。活动页通过 tiny_gfx 原有的 RGB565 / mask blit 输出，不透明内部与边缘覆盖率逐行分别提交。

起始、接触与结束时恢复原生字形 blit，保持静止画面的字形清晰度和中轴位置。进入桌面、副屏、熄屏或校时跳变时仍按已有状态管理取消动画。LCD 继续由唯一的 C display owner 提交，保留既有整屏 180° 校正。

## 卡片与背景的明暗层次

用户反馈卡片与整屏背景颜色相近后，将卡片提亮为炭灰色，拉开轮廓与黑色背景的差别。上下半页仍有明暗差，底部厚度和折线细部也同步提亮：

| 部位 | 原配色 | 当前配色 |
| --- | --- | --- |
| 整屏背景 | `#000000` | `#000000` |
| 上半页 | `#222222` | `#424242` |
| 下半页 | `#181818` | `#313131` |
| 卡片底部厚度 | `#080808` | `#181818` |
| 中轴下沿细线 | `#292929` | `#525252` |

静止页与活动页共享同一组颜色；角度明暗和软阴影沿用原有动画计算。使用 RGB565 通道强度接近的中性灰，避免提亮后引入明显偏色。配色调整的构建、刷写和实板反馈另存于 `acceptance-clock-contrast.json`。
