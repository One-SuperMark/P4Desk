# 文件管理

Pad 第二页的「文件管理」管理板载 TF 卡，沿用 Folio 深浅外观、图标主题、Home、关闭和启动动画。文件读写由单个后台存储任务处理，不在界面状态锁内执行。

## 设备操作

- 左侧选择 TF 卡根目录、我的文件、Documents、Pictures、Downloads 或回收站。首次正常挂载会建立 `Files`、`Documents`、`Pictures`、`Downloads`、`Fonts`，保留已有目录。
- 列表直接上下拖动，点击文件后在屏幕中央弹出详情与操作面板。文件夹进入下一层，上方返回按钮回到父目录。拖动时取消点按，防止误弹出。
- 搜索当前目录，可按名称、修改时间、大小排序。板上键盘输入 ASCII 名称；中文名称可从 Mac 上传。目录最多扫描 4,096 项、保留 256 项，超限会提示缩小搜索范围。
- 详情提供预览、重命名、复制、剪切和移到回收站。复制／剪切后进入目标目录再粘贴，同名文件不覆盖。
- 回收站提供恢复和永久删除。恢复不覆盖同名文件，永久删除有独立确认。
- 目录和排序随应用会话保存，重启重新读取目录；搜索、剪贴板、待执行操作和预览像素不写入会话。

`/sdcard/p4desk` 包含配置、便签、监控凭据和会话：允许浏览目录及元数据，禁止预览、复制、上传或修改。回收站内部记录和未提交文件不在普通列表显示。TF 挂载失败显示状态，不自动格式化。

## Mac 上传

1. 用 Type-A USB-OTG 数据口连接 Mac，打开 `/Applications/P4Desk.app`。
2. 在配置窗口选择「文件」，浏览 TF 卡并选择目标目录，默认 `Downloads`。
3. 点「上传文件」选择一个或多个普通文件。逐个显示字节数、进度、结果，支持取消。
4. 成功后目录刷新，Pad 可以直接打开传入的文件。先结束副屏或便签同步再上传。

单文件最大 **256 MiB**，内存中每块 **32 KiB**。设备写入同目录独占临时文件，按偏移接收；完整写入、关闭和持久化后，从 TF 卡流式重读校验 SHA256、长度，再提交文件名。中断、取消、超时和校验失败清理本次临时文件。重启只清理带本项目合法标记的未完成传输。

路径相对 `/sdcard`，空字符串为根，总 UTF-8 不超过 512 字节，组件不超过 255 字节。拒绝绝对路径、`.`／`..`、空组件、控制字符、反斜杠、FAT 非法字符和尾部空格／点。Mac 不上传文件夹、别名或符号链接，不覆盖同名文件。

## 预览边界

| 类型 | 支持范围 |
| --- | --- |
| 文本 | UTF-8 的 txt、md、json、csv、log、源码和配置；前 32 KiB，上下滚动，提示截断 |
| PNG | 灰度、RGB、RGBA、调色板和常见透明度；原图最多 1,048,576 像素 |
| JPEG | baseline 最多 16,777,216 像素、各边不超过 8,192，先 IDCT 缩略；progressive／lossless 最多 1,048,576 像素 |
| BMP | 未压缩 24／32 bit、上下行方向；最多 1,048,576 像素 |
| 其他 | 显示信息并可管理；PDF、Office 文档和媒体播放暂不预览 |

图片文件最大 4 MiB，输出最长 **640×400 RGB565**，按比例缩小居中，约 500 KiB。解码在后台执行，P4 的 JPEG 文件预览强制同步解码，不自动创建子线程；USB 副屏硬件解码独立保持。目录复制预检上限 1,024 项、12 层、64 MiB，逐块复制；移动和删除有项数及深度上限。

## 中文字形

Mac 合并文件名、目标目录名称、UTF-8 预览范围和此前字符，使用 HarmonyOS Sans SC 生成独立 14／18／22 字形包，上传到 `Fonts/P4Desk-<sha256>.p4f`。校验后单独保存指针，重启恢复；不替换便签字库。

包最大 8 MiB、16,384 条记录，本机字符集合上限 4,000。按需读取，有界缓存。缺失 Emoji 或超限时 Mac 明确提示，保留原字库，文件仍完整传入，无法显示的字符用占位框。直接放入 TF 卡的其他中文文件可能需要经 Mac 准备字形。旧包保留为普通文件，可清理未使用版本；请保留当前包。
