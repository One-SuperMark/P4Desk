# 资源、字形与持久化

## TF 代次

```text
/sdcard/p4desk/
  generations/
    .<generation>.pending/     正在接收；启动忽略
    <generation>/
      state.json              Snapshot：便签、按钮、删除记录
      font.p4f                同一代次所需的字形
      complete.json           代次、字形长度、SHA256
```

Mac 先生成本次便签和标签覆盖的字形，再发送 `sync_begin`、顺序资源块与 `sync_commit`。设备按 offset 和长度接收；检查 SHA256、P4F1 结构与四个字号的字符覆盖。文件 fsync／关闭、完整标记写入以及目录重命名成功后，Rust 替换当前快照与字形 provider，并触发立即重绘。

启动扫描数字代次目录，从新到旧检查完整标记、快照限制、字体长度／SHA256／覆盖情况。正在写入的目录和不完整代次不会生效，最新代损坏时可恢复上一完整代。旧完整代保留，便于断电恢复；TF 空间不足时本次同步失败，已有有效数据继续使用。

Flash 的设置和便签删除记录使用两个带版本／SHA256 的日志槽。更新写入较旧或损坏槽，保留当前完整槽；启动选择最新有效槽。SPIFFS 不能将文件重命名覆盖已有目标，因此这里不依赖该语义。

便签 ID 固定，删除记录优先于所有旧正文。删除成功后立即从界面移除，Mac 重连合并设备删除记录；要恢复便签需明确创建新的 ID。

## 字体来源与内存

- 系统界面汉字内嵌为 `assets/generated/ui.p4f`，TF 不可用时仍可显示基础工具。
- Mac 随包提供 Noto Sans SC Regular（SIL OFL 1.1）和 `p4desk-fontpack`。
- 同步字形来自当前便签／标签，包含 Unicode 标量和字号，无需设备加载完整 CJK TTF／OTF。
- TF 字形只加载索引，alpha8 图像按需读取。缓存限制为 512 KiB／512 项；整个字形包上限 8 MiB。
- 文字排版按字符回退，支持显式换行、中文自动换行与滚动视口裁剪。

Snapshot UTF-8 JSON 总量不超过 60 KiB，最多 32 条便签、48 个按钮。逐字段限制和 USB 包长度见 [协议 v1](protocol-v1.md)。

## P4F1 二进制格式

所有多字节值按小端序编码，读取时校验保留位、长度、排序、Unicode 标量和每块图像边界。

### 32 字节头

| 偏移 | 字段 |
| --- | --- |
| 0 | 4 字节 ASCII `P4F1` |
| 4 | u16，版本 1 |
| 6 | u16，单条字形记录大小 32 |
| 8 | u32，字形条数 |
| 12 | u32，表起点 32 |
| 16 | u32，alpha8 数据池起点 |
| 20 | u32，完整文件长度 |
| 24、28 | u32 保留，必须为 0 |

### 32 字节字形记录

| 偏移 | 字段 |
| --- | --- |
| 0 | u32，Unicode 标量 |
| 4 | u16，像素字号 |
| 6、8 | u16，字形宽、高 |
| 10、12 | i16，xmin、ymin |
| 14 | u16 保留，0 |
| 16 | f32，小端 IEEE754 advance，必须有限 |
| 20 | u32，alpha8 图像绝对文件偏移 |
| 24 | u32，alpha8 长度，等于宽×高 |
| 28 | u32 保留，0 |

记录按 `(size, codepoint)` 严格升序。每个像素一个 alpha 字节，UI 用当前文字颜色合成。

## 时间

Mac `time_sync` 使用 UTC epoch 毫秒和时区分钟，接受 2000-01-01 至 2100-01-01 的时基、−840 至 840 分钟时区，Rust 与 C 使用相同边界。越界返回 `time_invalid`，时钟和已保存时区不变。设置页支持 USB 重新校时与手动年月日／时分校时。计时服务以单调时钟计算，墙上时间校准不会影响倒计时。当前固件冷启动时间无效；持续供电时可离线运行。
